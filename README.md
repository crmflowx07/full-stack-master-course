# Full Stack Master Academy — ULTRA V4

A browser-based React learning academy for becoming a production-oriented Full Stack Developer.

## Live course
GitHub Pages deploys automatically from the `main` branch using GitHub Actions.

## Curriculum
- Web & developer foundations
- HTML, accessibility, CSS
- JavaScript
- Git & GitHub
- TypeScript
- React
- Node.js & Express
- REST APIs
- SQL/PostgreSQL
- MongoDB
- Authentication & security
- Testing
- Next.js concepts
- WebSockets, Redis & queues
- Linux, Docker, Nginx
- CI/CD & GitHub Actions
- Monitoring & performance
- System design
- DSA/interviews
- Portfolio & job readiness

## Academy features
- Light / Dark / System themes
- Persistent progress
- Bookmarks
- Personal notes
- Search
- Deep lesson sections
- Code examples
- Practice labs
- Debugging drills
- Quizzes
- Interview prompts
- Phase projects
- Capstone projects

Built with React ES Modules and deployed with GitHub Pages.
